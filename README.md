# ติดตามท่อนพันธุ์มันต้านทานใบด่าง กำแพงเพชร — หน้าเว็บเจ้าหน้าที่

หน้าเว็บสำหรับเจ้าหน้าที่ (เข้าสู่ระบบด้วยชื่อผู้ใช้ + PIN) ข้อมูลทั้งหมดอยู่ที่ Google Apps Script ของโครงการ ไม่มีข้อมูลเกษตรกรเก็บในที่เก็บนี้

ไฟล์ `index.html` สร้างอัตโนมัติจาก `admin.html` ด้วย `build_pages.js` — อย่าแก้ไขในนี้โดยตรง
